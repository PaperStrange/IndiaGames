## Known limitations

This is a staged candidate, not an official release. Physical-phone performance (30 FPS target), real player comprehension, enjoyment, reading time and motion comfort remain unverified. Durations shown in the collection are content estimates. Progress is browser-local and separate by story/profile; if device storage is blocked, the visit cannot survive a reload. Prior archive memories truthfully preserve that the original letter was published. Three.js requires WebGL2; unsupported or failed graphics fall back to a complete flat illustration. Both stories must pass human review before any main promotion; changing build bytes requires a new version and revalidation. There is no unrestricted AI dialogue or player-photo upload.
