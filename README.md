# Small Hours · Memorable Moments

A browser experiment for two people sharing one device: choose an activity, contribute together, and optionally keep or replay the result. This branch owns the implementation and its research; main owns the [studio dashboard](https://github.com/PaperStrange/IndiaGames/tree/main).

- [Human playtest checklist, blank records and November 20 plan](docs/gamejam/launch-2026-11-20/README.md)
- [Frozen baseline download, exact-artifact launch and protocol](docs/gamejam/milestone-2026-10-27/README.md)
- [Development run instructions](memorable-moments-game/play/README.md)
- [Research and historical evidence](docs/gamejam/README.md)

The current runtime is unchanged. Six real pairs, physical-device checks and an independent reviewer are still required. No official release is claimed; staging on master follows the pilot decision. Keep completed private records outside Git or in ignored `playtest-private/`, never in the blank template files.
