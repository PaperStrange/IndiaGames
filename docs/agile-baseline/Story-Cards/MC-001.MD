## User outcome

As a **delivery team**, I want **a verified gap map and versioned state contracts**, so that **we can implement the same behavior without losing prior decisions**.

## Why this work is needed

Alpha 0.4 has snapshots, private-owner fallback and lexical recall; these do not satisfy M0.

## Acceptance criteria

- [ ] **AC1.** Given the saved alpha 0.4 checkpoint, when the audit closes, then every M0 workstream maps to a code location, gap, owner role and acceptance test.
- [ ] **AC2.** Given an erase or rewrite during fading, when the contract is reviewed, then it explicitly keeps OCR jobs running, prevents stale application and starts new OCR only at the next input end.
- [ ] **AC3.** Given the proposed three-sprint M0 forecast, when owners estimate the gaps by day 3, then dates and scope are revised if capacity is insufficient; no baseline gate is waived.

## Implementation outline

1. Inspect auth/save/recall/provider paths and historical QA.
2. Specify operation ID, source/block version, owner scope, deletion and trace contracts.
3. Record unresolved choices and re-estimate with implementers.
