## User outcome

As a **notebook owner**, I want **derived memories updated when I correct or delete their source**, so that **old mistakes do not keep returning as facts**.

## Why this work is needed

Full dependency invalidation across memory and retrieval caches is incomplete.

## Acceptance criteria

- [ ] **AC1.** Given a memory derived from a source version, when that source is corrected, then the old derivative is invalidated or marked superseded before future use.
- [ ] **AC2.** Given deleted content, when an old client reconnects or recall runs, then tombstones prevent resurrection and forbidden-source use.
- [ ] **AC3.** Given 50 adversarial scope/deletion cases, when tested, then none uses forbidden content; concurrent corrections retain traceable history.

## Implementation outline

1. Record derivation links and invalidate caches/indexes.
2. Implement correction/deletion propagation and tombstone replay.
3. Test concurrent updates and stale jobs.
