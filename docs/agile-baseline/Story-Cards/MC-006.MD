## User outcome

As a **writer correcting a thought**, I want **regional edits that preserve the writing ritual**, so that **my correction cannot be overwritten by an old recognition job**.

## Why this work is needed

Accepted behavior exists in alpha; persistence and session changes must not regress it.

## Acceptance criteria

- [ ] **AC1.** Given settled input, when the 380 ms quiet threshold passes with no active pointer/IME/dialog, then recognition and the 5,000 ms fade share one start timestamp.
- [ ] **AC2.** Given an eraser touch during fade, when editing starts, then remaining text is restored before only the touched glyphs/stroke segments are cleared.
- [ ] **AC3.** Given an old OCR job and new writing, when the old result arrives, then the job has not been cancelled but cannot overwrite the current revision or start a stale reply.
- [ ] **AC4.** Given current recognition ready and fade complete, when the page is active, then at most one reply starts; failure restores input.

## Implementation outline

1. Reuse existing tests and add persistence/session regression cases.
2. Check typing, pen, erase, IME and page navigation.
3. Capture an end-to-end correction recording.

## Scope and readiness

Regression/polish card, not a fresh OCR accuracy claim or visual redesign.
