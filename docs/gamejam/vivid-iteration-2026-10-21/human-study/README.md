# Vivid human playtest preparation

**Prepared, not conducted.** There are no recruited participants, completed human sessions, physical-phone measurements or human release approvals in this packet. Agent gameplay and automated browser checks do not fill those gaps. All numerical criteria below are provisional acceptance rules for a small pilot, not validated estimates of market demand.

The planned study has **18 fresh adult participants in three separate cohorts**: six for Iona's remembered return, six for Iona's neutral return, and six for Mara's object-led story. Twelve people can satisfy the release evidence requirement if the neutral cohort cannot be recruited; that smaller study supports no remembered-versus-neutral comparison. Declare the intended cohorts before testing, preserve incomplete observations, and never hide an unfavorable neutral result.

- [Protocol and decision rules](protocol.md): freeze the artifact, preregister the sessions, apply the gate consistently.
- [Recruitment and screening drafts](recruitment.md): proposed copy and allocation; nothing has been sent.
- [Facilitator guide](facilitator.md): non-leading tasks, observation boundaries and debrief order.
- [Blank observation sheet](observation-sheet.md): behavior, quotes, errors, assistance, device data and metric adjudication.
- [Device and optional recall checks](devices-and-recall.md): physical hardware evidence and a separately declared delayed question.

The story implementation and authoring contract are described in the [story-pack guide](../../../../vivid-2.5d-photo-game/play/src/stories/README.md). The runtime code is [here](../../../../vivid-2.5d-photo-game/play/src/runtime/session.js). The release policy and schema-v2 blank templates belong to the separate release-tooling change on `main`/`master`; use the reviewed versions there, not an invented schema based on these prose sheets.

The three product questions remain hypotheses until people play: whether small authored actions motivate continued attention; whether remembered arrangements differentiate this experience; and whether giving an ordinary object personal meaning feels distinctive. The pilot can expose confusion, blocked interactions and specific responses. It cannot establish retention, broad preference, causal superiority or commercial demand.
