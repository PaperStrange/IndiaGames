# Vivid implementation contract (team working agreement)

Repo /workspace/IndiaGames, branch vivid-2.5d-photo-game. Play root vivid-2.5d-photo-game/play. Root owns index.html/styles.css/src/app.js/package.json/vite config, integration. No agent git switches/commits. Original rules/content stay as legacy baseline until root resolves.

## Story packs (story agent owns src/stories/**, test/stories.test.js)
Catalog at src/stories/catalog.js exports `catalog` array of `{id,title,subtitle,description,duration,load:()=>import('./iona/index.js')}`. IDs `iona` and `mara`. Each module exports named `pack` with manifest and pure functions. manifest `{id,revision:1,saveVersion:1,title,subtitle,description,duration,cast:{[actorId]:{name,pronouns,description}},assets:[{id,src,alt}],capabilities:['inspect','choose','place','adjust'],releaseProfile:'iona-return-v1'|'mara-object-v1'}`. assets may initially be empty; renderer owns common asset mappings.

Functions: `createState({profile='remembered'}={})`, `reduce(state,event)` returns new state; `getViewModel(state)`; `serialize(state)` JSON semantic state; `migrate({version,state})` returns valid current semantic state or throws. Iona additionally `migrateLegacy(v1Object,{profile})`. Runtime uses pack.manifest.saveVersion for envelope. Every event semantic; numeric/IDs validated by reducer. View/camera orientation is not serialized; transient feedback may reset. All reducer invalid/repeated actions safe.

View model `{title,kicker,speaker,text,phase,progress,scene,actions,inspection?,choiceSummary?,complete?}`. text string current narration. inspection optional `{title,text}`. `scene:{kind:'portrait'|'workbench',view:-1|0|1,actorId,light:'low'|'steady',placement:null|string,details:string[]}`. Extra scene fields allowed renderer ignores unknown. Actions descriptors share `{id,label,kind,event,disabled?,hint?}`. kind 'inspect'|'choose'|'place'|'adjust'. event is complete semantic event object (root sends without interpretation). `place` additionally `{objectLabel,destinationLabel}`; root offers click/select then tap target and native button keyboard; optional drag. `adjust` additionally `{value,min,max,step}`, event.value filled by input. Optional `appearance` string theme. All non-spatial gameplay can complete via these descriptors. 'choose' includes start, view left/center/right, ending, revisit etc. Group optional string for UI visual organization. UI must not contain Iona/Mara IDs/phase rules. Story rules decide visibility.

Story actions must include intentional return/revisit when ended; Iona completed saves open return directly (never repeat rescue). Legacy migrate sets truthful archive letterPublished=true; new archive false, dedication-only. Neutral profile fixed cloth placement on return. New recollection brace then wedge before choice. Optional old completed recollection accessible once, returns to return stage. Mara clue inspection any order then slider alignment reveal after all inspected, finish interpretive ending. Reset handled runtime outside reducer. story content structured files. Tests both choices+peek+neutral, legacy both, checkpoints, repeats, Mara orders/slider invalid and completion. Development recast fixture exported separately not catalog, engine no names hardcoded.

## Runtime (runtime agent owns src/runtime/**, scripts/validate-stories.mjs, test/runtime.test.js)
`createSession({pack,profile='remembered',storage=localStorage})` in src/runtime/session.js returns `{getState(),dispatch(event),subscribe(fn),reset(),dispose(),status,recover()}`. status readable `{kind:'ok'|'unavailable'|'corrupt'|'future',message}`. Save key `vivid:save:<storyId>:<profile>`. Envelope `{schemaVersion:1,storyId,contentRevision,storySaveVersion,profile,state}`. Preserve unknown future/corrupt saves; session may play in memory but must not overwrite until explicit recover/reset. reset only current story/profile, recover explicitly discards incompatible current record. storage exceptions no crash. For Iona only profile remembered, fallback legacy key keepers-frame:v1 if no new save, migrate; leave legacy key intact. persist every accepted dispatch semantic checkpoint via serialize; created state need not eagerly save. reset handles legacy so forgotten memory does not silently reimport (remove legacy only for Iona remembered). Subscribe callbacks after changes; dispose prevents writes/dispatch. profile remembered|neutral only; Mara default remembered. Save does not store pixel/animation positions. Safe pack validation exported by src/runtime/validate.js `validatePack(pack)` throws. Build script imports both catalog packs checks IDs, methods, JSON manifest, referenced public assets existence, action capabilities and text/accessibility on initial and per-story supplied validation states if available. Runtime helper `loadStory(entry)` validates loaded pack. Root handles async stale guards.

## Renderer/art (renderer agent owns src/renderers/**, public/art/**, art/**)
`createRenderer({container,onUnavailable})` async export src/renderers/world.js returns `{update(viewModel,manifest),setTilt(number),dispose(),stats()}`. Container only renderer content, UI outside. Root calls only after story loaded; all stories update through `scene.kind` generic portrait/workbench modes. onUnavailable(reason) root activates always available HTML/CSS flat stage. init asset/WebGL failures throw or call callback; context loss callback; no reducer/state mutation. All resources/listeners/RAF disposed; own late async loads guards. Import Three locally pinned by root. Source Blender and generated glb, authored SVG painted portrait/workbench art. Load public asset URLs relative to import.meta.env.BASE_URL for nested deployment. All assets original, no remote runtime CDN. root uses manifest.cast actorId to place painted SVG (can art expose asset path scene fields? use assets role id 'portrait' etc). Renderer no character name checks; scene fields decide visuals. Fallback DOM belongs root. active triangles <=100k DPR<=1.5; render-on-demand / brief easing only. Renderer should export `assetCatalog` if needed for validation (listsrcpaths). Source art export reproducible Blender4.3.2.

Release agent works outside checkout /workspace/vivid-release-update, reads git show main/master only. Research agents own docs/gamejam/vivid-iteration-2026-10-21/research/group-a or group-b. They may run browsers but never switch git or change story files.
