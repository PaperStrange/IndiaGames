## Browser comparison set

Before each session, copy the template and record operator, exact URL, date, browser/device, input method, audio access, task, time budget and stopping rule. Budgets below are maximum active observation windows, not expected human completion times. Record wall-clock/tool delays separately. Begin without a walkthrough; any later assistance starts a separately labelled assisted segment.

| Game and browser entry | Fixed first-session task | Budget and endpoint | Question for Notebook |
|---|---|---|---|
| [Line Rider](https://www.linerider.com/) | Draw a slope, try a safe landing, change one segment and compare the run | 20 min; record last actual construction/run, even if landing fails | Does visible geometry make failure understandable and repair rewarding? |
| [Sandspiel](https://sandspiel.club/) | Explore for five minutes; make a container and compare two material combinations with one variable changed | 20 min; two attempted comparisons or budget reached | When does material experimentation create a self-chosen next question? |
| [Townscaper](https://oskarstalberg.com/Townscaper/) | Build a small neighborhood, attempt a chosen feature, then remove an adjacent/supporting block | 20 min; document the feature reached or failed, then optional free continuation within budget | How do context-sensitive rules and personal goals sustain creation? |
| [shapez demo](https://shapez.io/) | Attempt first hub delivery, the next available transformation, then deliberately revise one line | 25 min; record unlocks actually reached, not the full advertised system | Can visible flow teach diagnosis, revision and growing complexity? |
| [Universal Paperclips](https://www.decisionproblem.com/paperclips/) | Start manual production, attempt first automation and one price/resource adjustment | 20 min; opening only, then an explicitly separate five-minute return on the following day if saved state survives | How does a changing role create progression, and when does interaction become routine? |
| [A Dance of Fire and Ice](https://fizzd.itch.io/a-dance-of-fire-and-ice) | Inspect calibration, play opening tutorials, attempt first complete track and up to two retries | 20 min or two track retries, whichever comes first; record exact level reached | Does immediate timing feedback support learning and voluntary retry? |
| [Draw a Stickman](https://drawastickman.com/) | Follow the opening episode; vary one requested drawing substantially on a separate attempt | 20 min; exact episode/step and whether comparison was reachable | Does authored drawing change behavior, appearance, or both? Can we detect cosmetic agency? |

For every game, record first purposeful action → prediction → consequence → failure/uncertainty → correction → voluntary variation → stopping. A complete record means the whole **attempted** journey is recorded; it does not mean the game was completed. Do not advance outcomes through hidden state, modify rules, accelerate timers or hide resets. Keep unsuccessful entry routes and inaccessible controls in the record.

The rhythm comparison needs audible observation to support claims about audiovisual timing or musical feel. If audio is unavailable, report that limitation and restrict findings to observed visual/control behavior; do not count it as an audio assessment. Universal Paperclips explicitly says its web version is not designed for phones. This is useful device-scope evidence, not a reason to impose that restriction on Notebook. Browser emulation is not a physical device test.

## Review and narrowing

Each research agent files the journey before recommending a concept. An independent reviewer checks screenshots/actions against claims, failed attempts, aids, timestamps and edition boundaries. Then compare the set through player, systems design, interaction/accessibility, art/narrative and operator lenses using the common template.

Do not average unlike games into a “fun score.” Identify which concrete mechanisms produced readable consequences, understandable recovery or self-directed variation, and which hypotheses remain unsupported. A blocked game counts as entry evidence only; resolve or replace the comparison question explicitly before calling mechanism coverage complete. A replacement needs its own recorded rationale and bounded task; it is not silently substituted into a claimed seven-game completion.

Select three mechanically different experiments only after the [decision matrix](DECISION-MATRIX.md) has evidence. Research can eliminate all candidates or reveal a new family. Keep that outcome available; the table is a starting field, not a promise to build every direction.
