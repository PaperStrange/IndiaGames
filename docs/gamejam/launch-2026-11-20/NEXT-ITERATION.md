## Minimum launch scope and deferrals

Ship **Iona and Mara as the reviewed catalogue** with existing local assets, authored narrative, browser saves, keyboard/touch equivalents, reduced motion and flat fallback. Do not quietly remove a failing story from the catalogue: that is a new scope/policy/build decision, not a way to pass the existing two-story gate.

Defer a third story, character-creation UI, unrestricted AI dialogue, photo upload, account/backend, native packaging, new platform integration and optional comparison studies if they compete with the launch evidence. Keep the flexible pack/cast architecture ready for later stories without expanding this release.

## Handoffs and safe checkpoints

One owner edits shared runtime/schema files; narrative/art can work in separate pack files after an agreed contract. Coordinator integrates sequentially in the shared checkout; stop owned servers before branch switches. Commit and push each accepted source/QA milestone, verify its remote SHA, and record the matching source/build/protocol IDs before master staging. Update the main dashboard separately; never merge a whole game branch into main merely to update planning.

Save a restart checkpoint at packet delivery, final candidate freeze and human go/no-go: completed work, exact refs/hashes, dirty files, unresolved checks, active owners and precise next commands. Remaining Codex allowance is unavailable; if the user reports below 5%, stop new work at a safe boundary, save and sync authorized clean work, then wait.
