## Scope control and fallback

- **Prediction/handoff friction:** one flow or copy experiment; reject it if reduced friction removes the curiosity that made the activity worthwhile.
- **Unequal contribution:** one complementary-prompt experiment; reject it if the second person still acts only after coaching.
- **Generic or draining ending:** one keepsake experiment; reject it if players still cannot recognize both contributions or choose to keep/repeat it.
- **No change:** retain the baseline if the actual evidence supports it and all independent release requirements pass.
- **Further study or stop:** use when participation is unwanted, evidence is missing, or the bounded change does not resolve its target. Do not combine several experimental changes to manufacture progress.

A missed Small Hours gate must not be hidden by a shared launch announcement. Other games may release independently if their own gates pass. Do not call Small Hours an official release until its own version, notes and real playable page have been verified. If no game passes, November 20 can be an honest progress update, not an official game release.

At each artifact/decision milestone, commit on the owning branch, push without force, verify the remote SHA, and update the main dashboard with pinned evidence. Keep a recovery bundle and a restart checkpoint containing completed work, pending checks, artifact IDs and exact next commands. Codex allowance is unavailable; if reported below 5%, stop new work at a safe boundary and wait after saving that checkpoint.
