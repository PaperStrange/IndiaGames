# Keeper's Frame (Vivid 0.1.2) — Concept Decision Brief (2026-10-28)

**Demo:** Keeper's Frame / Vivid 0.1.2 (Iona "A Place for the Promise" + Mara "The Unfinished Postcard"). **Audience:** the 20 November 2026 release gate. **Evidence:** first-hand Iona ending + return payoff + letter, Mara ending ([REAL]), competitor coverage (`coverage--vivid-0.1.2-2026-10-28.md`), journey + art records. Third-person throughout.

## §1 — Why play it

One frame, two visits, one letter. Vivid asks a player to read two harbour marks, call a ferry home, and then — the part no other game in its family does — come back. The return is where the game lives: the keeper asks why the wedge was kept, the player braces the shade, and the private letter opens ("To whoever keeps this light after me: I was frightened every night. I turned it on anyway. — Iona"). Mara is the same idea in one sitting: three objects, a lightbox, notch 3, and a picture that comes together ("The last train left. Someone kept a key."). The demo proves both stories end and the return pays off — first-hand, in one profile, in one context.

## §2 — Why choose it on this platform

| Competitor | What it does | Why Vivid instead |
|---|---|---|
| Birdography (free browser) | Photograph birds → journal fact, immediate payoff | Birdography pays per photo; Vivid pays only on return. The letter is worth more because it was waited for — but only if the player comes back. |
| Pixel Harbor (free browser) | Picture-logic; read clues → reveal a picture | The mechanic is satisfying alone; Mara adds a sentence at the end ("The last train left. Someone kept a key."). Logic + story beats logic alone. |
| The Star Named EOS ($14.99) | Photography as deduction, a whole game | The same idea in one frame instead of a whole game — a 15-minute story, not a 6-hour one. |
| Paper Trail ($19.99) | Fold the world to proceed | The tactile-puzzle instinct; Mara's lightbox (slider, steps, drag) accommodates hands the same way. |
| Lost Records: Bloom & Rage ($39.99) | Camcorder memory narrative, 1995 summer | Recording the past to understand it — Vivid's return visit is the same structure in miniature. |
| 1000xRESIST ($19.99) | Sci-fi narrative of memory and identity | The past as a place you visit; Vivid's loop is a gentler version of the same idea. |

No competitor in the six makes the second visit the payoff. That is the differentiator — and the risk.

## §3 — Distinctive experience (three candidates)

**Candidate A — the return is the product.** Iona's letter opens only on a return visit to the same story in the same context. Supported: the return ran first-hand — "Would you like to know why I kept that little wedge?" → "Brace the lamp shade" → "Open the private letter" → the folded letter. The letter is the payoff for returning, not for finishing. *Keep.*

**Candidate B — the single-frame puzzle is the product.** Mara's lightbox: three objects, align the sketches, notch 3, "Read the completed picture". Supported: the ending ran first-hand, with the picture's text ("The last train left. Someone kept a key. · An invitation to bring something broken. · The old room and a new arrangement, drawn on separate sheets."). *Keep as the second story.*

**Candidate C — the diorama is the product.** Rejected: the harbour is a frame to read, not a place to linger — there is no free exploration, no wandering. The frame is a puzzle, not a diorama; the Tiny Glade comparison fails on that point. *Reject.*

## Proposed decision

**Choose Vivid for the 20 November gate.** Both stories end first-hand; the return payoff is proven. The gate's job is the one thing a single profile cannot prove — whether six pairs return unprompted, and whether the notch (the return's trigger) is findable without coaching (Iona: at least 4/6 joint unaided completions + choice-to-return explanations, at most 1/6 unrestricted-AI expectations; Mara: at least 4/6 + action-to-visible-consequence explanations). Run the human gate before 20 November; watch unprompted returns specifically.
