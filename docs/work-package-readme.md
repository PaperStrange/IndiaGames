# The Thirteenth Bell — work package

A 3–5 session tabletop time-loop mystery set in one town, with a possible eventual Steam launch. Six locations: Bell Square, Glassworks, Saint Orra's Hospice, Flooded Archive, North Gate, Underbell. Canon: exactly one cracked bell, hanging in Bell Square tower's belfry.

## What's in this folder
- **time-loop-game-design-plan.pdf** — the full design dossier (rules, locations, NPCs, phases, clue graph, GM dashboard).
- **thirteenth-bell-town-map.webp** — the official canon town map with Dawn/Noon/Dusk/Midnight clock phases.
- **comparable-games-evidence-report.md** — research on 8 desktop time-loop/mystery games (Outer Wilds, Forgotten City, Twelve Minutes, Majora's Mask, Deathloop, Obra Dinn, Pentiment, Heaven's Vault) with real ratings, review counts, awards, player counts, and player quotes.
- **hands-on-browser-games-report.md** — 8 browser games actually played (Detective: Again!, PROMPTBOX, The Red Pearls of Borneo, Chekhov's Gun, Where Is Starlingdive?, Slice of Quest, Is this me?, Echo Diver) with loop mechanics, persistence models, deduction UX, repetition handling, and itch.io player data — plus honest records of games that couldn't run.

## The playable demo
**Flash Playable Game** (in the Hatch app) — a solo adventure on the official map, with an **Original / Contrast** toggle at the top:

- **Original** — map-based adventure, animated clock, predictions earn Momentum, Momentum skips mastered scenes, Fracture meter, Midnight Anchor Board, persistent scars.
- **Contrast** (research-driven) — two-view journal (Place view by district + Theory view as a string-and-pin causal board with redacted-until-proven entries), NPC × phase planning ledger with prediction-before-travel, automatic compression of mastered scenes, delayed batched theory validation at phase boundaries, and a web-companion/tabletop-kit split: the demo carries the feel, the plan book carries the full system.
