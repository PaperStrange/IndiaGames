# MC-031 — Keep a complete input turn when it needs several leaves

Type: Story. Priority: P1. Status: Proposed, next-sprint refinement. Owner roles: Client + AI + QA; people unassigned. Estimate: unestimated. Dependencies: MC-003, MC-006, MC-021, MC-022. Related: MC-029.

As a writer developing a long thought, I want my typed or recognized passage to continue across leaves as one turn, so that every word remains editable and the companion receives the complete thought once.

## Acceptance criteria

- [ ] Typed text and vision transcription spanning at least three leaves preserve all substantive text, names, numerals, negation and original-ink references.
- [ ] Placement uses the rendered bounds of existing blocks and annotations. The notebook dimensions stay fixed; existing content is not obscured or relocated.
- [ ] One turn ID owns its fragments and input revisions. Explicit submission sends the complete current turn once; navigating between fragments never submits partial passages independently.
- [ ] Erasing or correcting a fragment updates the intended text and source reference without restoring independently erased text. In-flight recognition completes and remains subject to revision guards.
- [ ] Interrupted recognition, application restart, provider failure and page-limit cases retain recoverable input; the UI explains the available action without losing the draft.
- [ ] Actual provider and physical-device evidence includes crowded existing pages, margin writing, mixed languages and out-of-order completion. Text-only layout tests do not close recognition accuracy criteria.

## Implementation and evidence

Introduce a turn-level input model with ordered page fragments and source spans. Extend the current fixed-page layout and original-ink recovery to that model. Atomically journal page fragments with the turn before submission. Reuse MC-022's consented annotation benchmark and MC-021's device matrix.

Current behavior retains original ink or composer text when a complete passage cannot fit one leaf. This card removes that input-length boundary. Evidence required: complete-turn provider trace, geometry/text preservation checks, correction recording and restart recovery.
