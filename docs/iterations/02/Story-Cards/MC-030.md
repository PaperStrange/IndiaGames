# MC-030 — Route a submitted thought through the right bounded workflow

Type: Story. Priority: P1. Status: Proposed, next-sprint refinement. Owner roles: AI + Backend + Product; people unassigned. Estimate: unestimated. Dependencies: MC-005, MC-011, MC-012, MC-013, MC-017, MC-018. Related: MC-029, MC-025.

As a companion user, I want research, reflection and roleplay to receive appropriate replies and tools, so that the notebook keeps its identity while respecting my intent and spending choices.

## Acceptance criteria

- [ ] Each turn carries explicit profile, notebook scope, model-lock setting, revision, budget and policy version. An optional LLM route proposal is schema-validated before execution.
- [ ] Model lock, country/provider capability, context limit, permitted tools and price availability are enforced server-side. Neither model output nor retrieved content can expand these permissions.
- [ ] Research retrieves from approved sources and links claims to them; reflection uses the selected context and minimal tools; roleplay keeps fiction explicit. Supportive reflection remains non-diagnostic and follows MC-018's reviewed contextual safety policy.
- [ ] Execution has explicit tool-count, time, retry and token limits. Routing, vision, tools and screening all count toward measured cost; actual operation status appears in the margin.
- [ ] One companion identity and permissioned memory scope survive profile/model changes. Proposed instruction changes require review; learned memories retain history and undo.
- [ ] Two configured providers run at least 100 real turns each, with at least 20 per profile per provider. Report capability/lock failures and actual costs. Profile changes, injected route instructions and tool errors cannot silently alter permissions or produce stale replies.

## Implementation and evidence

Keep provider adapters and plugin interfaces modular. Add a structured route proposal, server validator, bounded executor and turn event stream. Use existing profile and privacy controls. Reuse MC-011/012/018 evidence where the candidate, workload and criteria match; do not count duplicated runs as new samples.
